  the property object, so `.fset(...)` is the one edge at `model.py:692`

  clarification on outside names; the micro-benchmark's "path as the
  snippet reaches it" gives the same name, `datetime.datetime.fromisoformat`.

- **J4 (the response of `download`).** Agree. `load` passes any URI with a
  scheme to the default opener; the docstring and the README say "uri"; the
  asciinema precedent admits an `addinfourl` (there after a redirect). The
  five edges that rest on `file:`, `data:` and `ftp:` URLs stay. This is the
  only call that a reader could dispute; it decides 5 outside edges and no
  inside edge, so it needs no ruling.
- **J5 (`custom_tags_parser`).** Agree: B5; no document or test passes a
  package function there.
- **J6 (`str()` of package objects).** Agree, site by site.
