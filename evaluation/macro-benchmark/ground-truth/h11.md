## Architecture, as the ledger uses it

- `Connection` (`_connection.py`) keeps a `ConnectionState` (`_state.py`),
  a `ReceiveBuffer` (`_receivebuffer.py`), and two callables: `_writer` and
  `_reader`. `_get_io_object` selects them from the tables `WRITERS`
  (`_writers.py:136`) and `READERS` (`_readers.py:235`).
- The states, roles and switch markers are classes made with
  `metaclass=Sentinel` (`_util.py:107`). `Sentinel.__new__` sets
  `v.__class__ = v`, so the type of each sentinel is the sentinel itself.
  `repr()`, `str()` and `format()` of a sentinel therefore run
  `Sentinel.__repr__`.
- The events (`_events.py`) are frozen dataclasses. All except
  `ConnectionClosed` define `__init__` explicitly. Dataclass-generated
  methods (`__eq__`, `__repr__`, `__setattr__`, and the `__init__` of
  `ConnectionClosed`) have no node.
- `Headers` (`_headers.py:77`) is a `collections.abc.Sequence` subclass. It
  defines `__getitem__`, `__len__`, `__bool__`, `__eq__` and `__repr__`.
  Iteration uses the `Sequence.__iter__` mixin, which calls `__getitem__`.
  `list(headers)` calls `__len__` (length hint) and then `__getitem__`.

## Scope rules

`macro-benchmark/README.md` ("Scope rules") states the rules A, B1-B5 and C
for all 30 projects. This section shows how the h11 ledger applies them.

**A. Edges are per function.** Every function keeps the out-edges of its
body, whether and how it is called.
- `Headers.__eq__` and `Headers.__repr__` have no package caller, but they
  keep all their out-edges (3 and 4).
- The three dead functions (`_ResponseBase.__post_init__`,
  `BodyWriter.send_data`, `BodyWriter.send_eom`) have no out-edges because
  their bodies are only `pass`, not because they are dead.
- One trace edge is rejected: `_obsolete_line_fold -> <builtin>.bytearray`.
  The private helper receives bytearrays from package callers. Only a
  direct test with bytes reaches its defensive cast (_readers.py:53).

**B1. Receivers.** Private functions use the package's actual call inputs.
An uncalled private function keeps its body under A and uses the public-
parameter fallback. A receiver must be constructible: failed argument
binding enters no function, while an entered body that raises keeps its
calls. Failed construction supplies no completed instance; clients do not
reinitialize instances or reuse arbitrary half-changed objects. Direct
public `ProtocolError(...)` enters its initializer and raises `TypeError`
there; it does not supply a completed `ProtocolError` instance.

- `self.__post_init__()` (`_events.py:166:27`): the callees are
  `InformationalResponse.__post_init__` and `Response.__post_init__`.
  `_ResponseBase.__post_init__` is rejected. `_ResponseBase` is private
  (rule C), and the package never instantiates it: it creates `Response`
  at `_connection.py:654`, and `class_` at `_readers.py:113` is
  `InformationalResponse` or `Response`. Both subclasses override the
  method.
- `self.send_data(...)` and `self.send_eom(...)` in `BodyWriter.__call__`
  (`_writers.py:65:27`, `67:26`): `self` is a `ChunkedWriter`,
  `ContentLengthWriter` or `Http10Writer`, the classes of
  `WRITERS[SEND_BODY]` that `_connection.py:334` instantiates. All three
  override both methods. `BodyWriter` is private (rule C) and the package
  never instantiates it, so `BodyWriter.send_data` and
  `BodyWriter.send_eom` are rejected.
- `self(buf)` (`_readers.py:190:28`): `self` is a `ChunkedReader`; the
  package defines no subclass of it.

**B2. Arguments and stored values.** A package value is in scope for a role
when the annotation names its type, or when the package's own code, tests
or documented examples pass it there. When an annotation exists, it decides
which package values fit. Broad `Any`, `object`, `type` and `Callable` do
not admit arbitrary package objects. Public attribute assignment requires
a source, documentation or test witness for that role.

- `_connection.py:175:63` (`{our_role!r}`): `our_role` is `Type[Sentinel]`
  (`_connection.py:169`). Every sentinel class fits, for example `h11.IDLE`
  passed by mistake. Its type is itself, so `repr()` runs
  `Sentinel.__repr__`: the edge `Connection.__init__ -> Sentinel.__repr__`
  stays. The tests pass the str `"CLIENT"`, which runs no package code, so
  the trace does not have this edge.
- The annotation excludes `Headers` (and the events) at these sites, so
  seven edges are not in the graph, and no test makes them:
  - `Connection.__init__ -> Headers.__repr__` (`our_role: Type[Sentinel]`:
    a `Headers` or an event is not a class);
  - `Connection.receive_data -> Headers.__bool__` (`data: bytes`);
  - `bytesify -> Headers.__getitem__` and `bytesify -> Headers.__len__`
    (`bytes(s)` at `_util.py:135`; `s: Union[bytes, bytearray, memoryview,
    int, str]`);
  - `ContentLengthWriter.send_data -> Headers.__len__`,
    `ChunkedWriter.send_data -> Headers.__bool__` and
    `ChunkedWriter.send_data -> Headers.__len__` (`Data.data: bytes`).
- `list(other)` in `Headers.__eq__` (`_headers.py:111:34`): `other` is
  annotated `object`. A `Headers` is in scope there because the tests pass
  it: they compare events (`test_connection.py:212`), and the generated
  `__eq__` of two events compares their `headers` fields. So
  `Headers.__len__` and `Headers.__getitem__` are callees.
- `Headers` passed back in as `headers=` fits (annotation
  `Union[Headers, List[...], ...]`, and `_connection.py:654` does it). It
  adds no edge: the constructors keep a `Headers` behind an `isinstance`
  test and call `normalize_and_validate` only for other values.
- The 11 `write(...)` sites in `_writers.py`: `write` is typed as a bare
  callable (`Writer = Callable[[bytes], Any]`), which is no evidence for a
  package value. The package's own code passes only `data_list.append`
  (`_connection.py:571`), so the callee is `<builtin>.list.append`.
- `msg.format(*format_args)` (`_util.py:90:29`): `validate` is private. Its
  package callers pass `bytes` and `bytearray`s. The int passed by the
  direct private-helper test (`test_util.py:80`) does not widen these inputs.
  No package object is formatted.

**B3. Not considered.** The package never gives a client a
`ReceiveBuffer` (`Connection._receive_buffer` is private; `trailing_data`
returns `bytes`), nor a reader or writer object, and it never produces one
for a client-facing parameter. This rejects the `ReceiveBuffer` candidates
at `bytesify`, `receive_data`, the writers and `list(other)` in
`Headers.__eq__`.

**B4. Concrete outside types.** A method call on a parameter whose
annotation fixes an outside type is an edge to that type's method:
`regex.fullmatch` (`Pattern[bytes]`) gives `re.Pattern.fullmatch`,
`msg.format` (`str`) `<builtin>.str.format`, `s.encode` (`str` after
`isinstance`) `<builtin>.str.encode`, `name.title` (`bytes`)
`<builtin>.bytes.title`, `io_dict.get` (`Dict`) `<builtin>.dict.get`.
Shipped stubs count as annotations; h11 ships none. Annotations take
precedence over conflicting documentation. `Any` supplies no type
information. An abstract annotation does not fix a concrete outside class;
an abstract `isinstance` check does not override a concrete class documented
for that parameter. Client callbacks and their results remain opaque.

**B5. Client objects are opaque.**
- `_headers.py:158:24` (`for name, value in headers` in
  `normalize_and_validate`): the package passes lists here, and a `Headers`
  never reaches the loop. An iterable that the client supplies is opaque,
  whatever it is built from (`itertools.chain(req.headers, extra)`,
  `reversed(req.headers)`). `Headers.__getitem__` is rejected and
  `Headers.__len__` excluded.
- The `Data.data` placeholder object of `send_with_data_passthrough`
  (`_writers.py:89, 105, 107`): its `__len__` and `__bool__` are client
  code.

**C. "Public" is judged on the access path.** The public classes and
functions are the ones that `h11/__init__.py` re-exports: `Connection`, the
events and `Event`, the sentinels, and the three errors. No public path
reaches `_ResponseBase`, `BodyWriter`, `Headers`, `ConnectionState`,
`ReceiveBuffer`, `Sentinel`, the readers and writers, or the functions of
`_headers`, `_readers`, `_writers` and `_util` (`h11/__init__.py` imports
only the error classes from `_util`). `BodyWriter` is private because
nothing re-exports it; `_ResponseBase` is private for the same reason, and
by its own name. A client still gets `Headers` instances, which the package
creates (`event.headers`).

**Naming of `super().__init__()` in the events** (`_events.py:91, 146,
345`). The MRO after the event class is `Event` (no `__init__`), `ABC`,
`object`. The method that runs is `object.__init__`. It is named
`abc.ABC.__init__`, through the nearest base outside the package, as the
README says. The trace's canonical name is `<builtin>.object.__init__`;
the checker accepts both. `ProtocolError` calls `Exception.__init__(self,
msg)` explicitly, so that call is `<builtin>.Exception.__init__`.

## Judgement calls

1. **`if TYPE_CHECKING:`** (`_headers.py:7-8`) only imports `Request` for an
   annotation. It has no call. The truth site `7:4` is rejected (a bool).
2. **Optional import** (`_headers.py:10-13`): `typing.Literal` exists on
   all admitted Python versions (3.8+), so the `typing_extensions.Literal`
   fallback does not run. Neither side has a call.
3. **Version branches**: none. Python 3.14 evaluates annotations lazily
   (PEP 649) instead of at definition. The annotations only subscript
   `typing` objects, so this changes no edge.
4. **`ConnectionClosed()`** (`_connection.py:433`): its `__init__` is
   generated by `dataclass`. It has no node and gives no edge (micro-benchmark
   case `stdlib_classes/dataclass_default_factory`). It has no fields and no
   `__post_init__`, so it calls no package code. The site has a note and no
   callee.
5. **Decorators `@dataclass(...)`** (`_events.py`, 7 sites): the call gives
   `dataclasses.dataclass`; the decorator applies its local function
   `wrap`: `dataclasses.dataclass.wrap` (micro-benchmark case
   `stdlib_classes/dataclass_order`). `wrap` calls no package code: no
   field defaults, no `__set_name__`, and `init=False` (except
   `ConnectionClosed`, which has no `__post_init__`).
6. **`str.format` and f-strings of sentinels** (`_state.py:310`,
   `_state.py:359`, `_connection.py:175`): `format()` falls back to
   `str()`, then `repr()`, on the sentinel, which runs `Sentinel.__repr__`.
   The trace confirms the two `_state.py` edges.
7. **Truth tests and `len()` of the `ReceiveBuffer`**: `ReceiveBuffer`
   defines `__bool__`, so a truth test calls `__bool__` only; `__bool__`
   calls `__len__` itself (`_receivebuffer.py:58`). Truth tests of `Headers`
   at `_writers.py:97, 121` call `Headers.__bool__` only. That method calls
   `bool` on its underlying list, not `Headers.__len__`.
8. **Header names and values**: ordinary construction uses `bytesify`
   or `re.Match` groups, which are `bytes` also for a `bytearray` subject.
   The ordinary callees are `<builtin>.bytes.lower`, `.split`, `.strip`,
   `.title`. The public `_parsed=True` keyword can preserve strings under
   optimized execution; judgement 12 records the extra calls and cutoffs.
   The buffer lines
   from `ReceiveBuffer.maybe_extract_lines` are `bytearray`s
   (`<builtin>.bytearray.split`, `.endswith`, `.find`).
9. **Implicit comparisons that reach no package code**:
   `event not in [NEED_DATA, PAUSED]` (`_connection.py:482`) compares a
   sentinel with an event; the dataclass `__eq__` returns `NotImplemented`
   for another class, so no `Headers.__eq__` runs. Sentinel classes hash
   and compare with the methods of `type`/`object`.
10. **Formatting with `%` and `str.format`** (the site finder proposes the
    `__str__`, `__repr__` and `__bytes__` of package classes there). The
    operands are builtin at every site except `_state.py:310`:
    - the 9 `.format(**globals())` sites of `_abnf.py`: the fields name
      module-level str constants;
    - `_events.py:210, 250` and `_readers.py:139`: ints (`status_code`,
      lengths);
    - `_util.py:90` (`msg.format(*format_args)`): bytes and bytearrays from
      package callers; the direct private-helper test int is excluded (B1);
    - `_headers.py:117:32` (`"<Headers(%s)>" % repr(...)`): a str;
    - the bytes `%s` sites `_writers.py:29:33, 32:33, 39:33, 58:33`: the
      ordinary header fields, method, target, status and reason are `bytes`.
      Unnormalized str inputs can fail bytes formatting (including a public
      InformationalResponse with `_parsed=True`), but do not admit a
      `ReceiveBuffer`; client-subclass conversion remains opaque (B5);
    - `_state.py:310`: `Sentinel.__repr__` is a callee (judgement 6);
      `Headers.__repr__` is rejected.

11. **Documented terminal error state** (`_connection.py:479`): the API
    documents that a receive failure sets `their_state` to `ERROR` and that
    later `next_event` calls raise (`docs/source/api.rst:478-486`);
    `test_connection.py:905-918` checks this guarantee. `_process_error`
    deliberately completes this terminal transition. This state is supported
    API behavior, not arbitrary reuse of a half-changed object. The send-side
    guard at line 553 is also reached after a successful public `send_failed`
    call. These witnesses preserve the existing sites and edge pairs.

12. **Optimized execution and public constructor inputs**. `_parsed` is an
    accepted bool keyword of public event constructors. C makes access paths
    private, not keyword names. With assertions enabled, strings passed with
    `_parsed=True` stop at `_headers.py:167-168`. Under `-O`/`-OO` those
    assertions disappear. `Response(status_code=200, headers=[('X', 'v')],
    _parsed=True)` reaches `str.lower` at `_headers.py:171`.

    A name that subclasses `str` still fits `List[Tuple[str, str]]`. Its
    `lower` override can return an opaque result comparing equal to
    `b'content-length'` or `b'transfer-encoding'`. B5 excludes the override
    and its result as callees, but includes their control-flow effects.
    With the exact str value `'1'`, the content-length branch enters
    `str.split(b',')` at line 173. Argument binding succeeds; the builtin
    body raises TypeError. With `'chunked'`, line 196 calls `str.lower`
    before the bytes comparison rejects the value.

    For downstream calls, construct a Request with bytes method/target and
    `_parsed=True`, and str pairs `(Name('host'), 'x')` and
    `(Name('connection'), 'close')`. `Name.lower` returns an object that
    compares equal to the matching bytes spelling. Under `-O` construction
    completes: host counting and the two byte-pattern validations succeed.
    Sending it on a fresh client Connection reaches `_keep_alive` and
    `get_comma_header`. The raw value `'close'` calls `str.lower` at line
    248, then its str result enters `str.split(b',')` at line 249 and raises
    within the builtin. No failed object is reused and no arbitrary public
    attribute is changed. The concrete raw string is a constructor argument
    stored by the package; the name override only controls branch choice.

    These are four added outside pairs at five sites. No `str.strip` edge
    follows: exact str.split fails first, while a client split override's
    result remains opaque. Other assertions concern fixed package states,
    table-selected event types, counters or buffer shapes and add no target.
    There is no runtime `__debug__`, `__doc__` or `inspect.getdoc` dependency;
    `-OO` adds no further edge.
