# Q10. Client behaviour as a witness: does B5 admit it?

Adopted by the lead in place of a referee, maintainer's instruction of
2026-11-28. Read at `c7fc8fb3`. Paths are relative to
`evaluation/macro-benchmark/`; a package's files are cited from its root
under `projects/<name>/`, its ground truth is under `ground-truth/`, and
`benchmark-rules.md:<n>` is a line of `evaluation/benchmark-rules.md` at
that commit.

**1. The question.** Several ground truths reach package code through
what a client value does or is, without naming a client callee. Does B5
admit these witnesses?

| Kind | Package | Site / pairs | Witness in the judgement |
|---|---|---|---|
| hash match | netaddr | `IPSet`, `SubnetSplitter`, `cidr_*` set and dict sites -> `BaseIP.__eq__` (`netaddr.md` J9, J10; notes at e.g. `netaddr.ledger:3583`) | two IPv6 networks whose ints are equal modulo 2**61 - 1; bundled IANA keys that collide under CPython 3.7's tuple hash |
| hash match | tinydb | `LRUCache.get`, `.set`, `.__contains__`, `.__delitem__` -> `QueryInstance.__eq__`, `__hash__` (`tinydb.md` J2; `utils.py:78`, `101`, `105`, `111`) | equal queries (traced); `hash(-1) == hash(-2)`; a plain int key whose hash equals a stored query's hash |
| equal or colliding keys | fabric | `group.py:148:24`, `150:24`, `248:31`, `250:32` -> `Connection.__eq__` (`fabric.md` J8) | `SerialGroup('h', 'h')` (equal identities); ports equal modulo the hash modulus |
| `__getattr__` fallback | bottle | 30 site entries `-> BaseRequest.__getattr__`, 21 of them added in the 2026-11-16 audit (`bottle.md` "Fourth complete audit") | a client `dict` subclass as `environ` whose `get` or `in` raises `AttributeError` inside a request property |
| `__getattr__` fallback | anytree | 18 pairs, 22 site relations (`anytree.md` R4-F1) | a client `Node` subclass whose `parent`/`children` getter raises `AttributeError` inside an inherited `NodeMixin` property of a `SymlinkNode` |
| `__getattr__` fallback | asyncstdlib | 7 pairs at `_lrucache.py:142`, `171`, `175`, `179`, `183` (`asyncstdlib.md` "Round4 descriptor-fallback supplement") | a client `LRUAsyncCallable` implementation whose metadata property raises `AttributeError` |
| warning as error | structlog | `to_repr -> twisted.ReprWrapper.__repr__` at `tracebacks.py:173:32` | `-W error::RuntimeWarning` turns the deliberate `warnings.warn` of `ProcessorFormatter.format` (`stdlib.py:1206-1212`) into a raise whose frame holds `ed`, a tuple with a `ReprWrapper` |

**2. The ruling.** **Apply B5 with the 2026-11-15 clarifications; no
change.** Hash and equality calls that a dict or set makes on admitted
values are interpreter behaviour, not client behaviour; an exception that
a client method raises is a client effect on control flow, and the
package code that Python runs because of it (a `__getattr__` fallback)
has its edges; a documented warning filter that turns a warning the
package issues on purpose into an exception makes a raise that the
package makes on purpose.

Scope: this names no client method or result, admits no client-defined
`__eq__` or `__hash__` as a callee, and keeps the no-reuse-after-failure
rule.

Effect: 0 edges in tinydb, fabric, netaddr, bottle, anytree, asyncstdlib
and structlog; no text of `benchmark-rules.md` changes.

For the audit: structlog's edge also needs `twisted.JSONRenderer`
admitted as the last processor of a `ProcessorFormatter` (the ledger's
processor set P at `stdlib.py:1202:19`) under B2, the role that gives
`to_repr -> ReprWrapper.__repr__`; this question does not raise it and it
was not re-derived here.

**3. What the rules say.**

- B5 (`benchmark-rules.md:2172`): "A method call on a client-supplied
  object ... has no outside callee, and what the object calls when the
  package uses it is client behaviour." "An exception that escapes a
  client callback is a client value (bottle: `_raise`)."
- Clarifications (2026-11-15), "Client control flow (B5)"
  (`benchmark-rules.md:2256`): "Client methods and callback results stay
  opaque, but their effects on control flow count. An admitted subclass
  can override operations; repeated truth or length checks need not
  agree. A witness must use the public API without modifying package
  internals or reusing an object left half-changed by a failure."
- "Call sites and candidates" (`benchmark-rules.md:3283`): "A dict or set
  calls `__eq__` of a key when two keys have the same hash, also when no
  two are equal: CPython hashes integers modulo 2**61 - 1, so two IPv6
  networks of netaddr can collide, and its sets and dicts of networks call
  `BaseIP.__eq__`".
- Edges (`benchmark-rules.md:1845-1862`): an edge counts "if some program
  that uses only the public API makes it in a fresh process"; "After Codex
  audit round 1" (c) (`benchmark-rules.md:2546`): that "sets no threshold
  of probability".
- Clarifications, "Versions and configuration"
  (`benchmark-rules.md:2261`): "Documented interpreter or library
  configuration counts when it changes a package-owned default or value";
  the nodeenv ruling (`benchmark-rules.md:2972`): a library setting
  changed through the library's documented interface is not a change of
  package internals. B2 (`benchmark-rules.md:2082-2086`): "the locals of
  the package's own frames, on a raise that the package documents or makes
  on purpose, are package values".

The rules decide all three kinds:

- Hash matches are not client behaviour. The receivers are package
  objects (or a package object and a builtin `int`), and the comparison
  is the dict's or set's, on admitted values: the "Call sites" text
  decides netaddr in words, and the fresh-process rule with ruling (c)
  admits a value that collides for some inputs or hash seeds (tinydb's
  str field names under `PYTHONHASHSEED`). fabric's J8 does not need a
  collision: two equal Connections are distinct objects with one
  identity, so the second `results[cxn] = ...` compares them.
- `__getattr__` fallbacks are the "effects on control flow" of the
  2026-11-15 clarification: the client method raises `AttributeError`,
  an opaque client action; Python's attribute protocol then calls the
  package's own `__getattr__` (a package callee of the package site), and
  no client method or result is named. The witnesses use a first
  operation on a freshly built object (the clarification's last
  sentence).
- Warning as error: `-W error` and `warnings.simplefilter("error")` are
  documented interpreter and library configuration; under them Python
  raises the package's own deliberate warning in the package's frame, so
  that frame's locals are those of a raise the package makes on purpose.

**4. The evidence.**

- CPython's dict lookup compares a stored key with the probe when the
  hashes are equal and the objects differ (`Objects/dictobject.c`,
  `PyObject_RichCompare(startkey, key, Py_EQ)`; the rule text above
  states it); `hash(-1) == hash(-2) == -2` on CPython.
- fabric `connection.py:425-442`: `__eq__` and `__hash__` use `(host,
  user, port)`; `group.py:148-150` stores each Connection as a
  `GroupResult` key.
- tinydb `utils.py:78` `del self.cache[key]`; `QueryInstance.__hash__`
  hashes a tuple built from the client's field names and values
  (`queries.py:96-100`).
- bottle, anytree, asyncstdlib: Python calls `__getattr__` when
  `__getattribute__` raises `AttributeError`, also when the attribute is
  a property whose getter raised it (data model, "Customizing attribute
  access"). The witnesses are in the cited judgements (anytree's W1,
  `anytree.md:394-400`; the asyncstdlib supplement).
- structlog `stdlib.py:1205-1212`: `if not isinstance(ed, str):
  warnings.warn(..., category=RuntimeWarning, stacklevel=1)`; `to_repr`
  (`tracebacks.py:160-178`) calls `repr(obj)` on each frame local. Python
  logging's `Handler.emit` swallows the exception (`handleError`), so the
  witness program calls `formatter.format(record)` (public, inherited
  `logging.Formatter.format`) itself, catches the `RuntimeWarning`, and
  logs it through a structlog logger with the dict-traceback processor
  and `show_locals=True` (`tracebacks.py:430`).

**5. Against.** "Effects on control flow count" makes any client
exception at any point a witness, so every `__getattr__` of a package
class becomes a callee wherever a property of that class calls client
code. The clarification accepted that cost; the asyncstdlib and bottle
defaults were rewritten to match it. A narrower rule ("only exceptions
that the documentation or tests show a client raising") would remove the
2026-11-16 additions (bottle 21 site entries, anytree 18 pairs,
asyncstdlib 7 pairs) and would reverse a global clarification.
